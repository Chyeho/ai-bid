# AI 标书审核系统 — 开发流程

## 项目概述

AI 辅助招投标文档审核系统。输入 PDF 或 DOCX 格式的标书文件，自动提取
结构化内容（文本、表格、关键词坐标），供下游 LLM 进行合规性审核、
条款比对、格式检查等。

## 环境依赖

| 依赖 | 用途 | 安装方式 |
|---|---|---|
| Rust (edition 2024) | 主程序，PDF 解析主引擎 | `rustup` |
| Python 3.x + pdfplumber | PDF 解析兜底（容错更强） | `pip install pdfplumber` |
| LibreOffice 26.x | DOCX → PDF 转换 | [下载](https://www.libreoffice.org/download/) |

## 处理流程

```
输入文件
  │
  ├── .pdf ──→ pdf_extract_service
  │              ├── ① Rust lopdf 解析
  │              │     └── 成功 → RawDocument
  │              └── ② 失败 → Python pdfminer.six 兜底
  │                    └── 成功 → RawDocument
  │
  └── .docx ──→ docx_convert_service
                   └── LibreOffice --headless → .pdf
                        └── 走 PDF 管线 ↑
                                    │
                              ┌─────┘
                              ▼
                      文本清洗管线
                        ├── clean_layout_text()
                        │     · 删除空白行
                        │     · 合并拆散汉字（竞 争 性 → 竞争性）
                        │     · 压缩连续空格
                        └── 空白占比 > 80%？
                              └── reconstruct_text_from_words()
                                    · 按 y 坐标分行
                                    · 按 x 坐标排序
                                    · 检测列间距自动分块
                              │
                              ▼
                        RawDocument JSON
                    （干净文本 + 单词坐标 + 表格）
```

## 文本清洗说明

政府标书多由方正排版系统生成，PDF 内部对**每个字符独立绝对定位**，
导致 `layout=True` 提取的 text 包含大量排版空格（99% 空白）。
清洗管线自动检测并重建为可读文本，压缩比约 **50:1 ~ 80:1**。

## CLI 用法

```bash
# PDF 输入
cargo run -- tests/智慧教室环境改造工程.pdf

# DOCX 输入
cargo run -- "tests/东莞理工学院...docx"

# 输出: tests/<文件名>raw.json
```
