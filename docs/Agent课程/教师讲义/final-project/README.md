# 毕业设计材料清单

本目录下的文件在发布大作业时下发给学员。

---

## 文件说明

| 文件 | 用途 | 给谁 |
|---|---|---|
| `测试标书.txt` | 学员审核的目标文件 | 学员 |
| `法规库/` | 学员的 Agent 搜索用 | 学员 |
| `expected_findings.md` | 讲师验收参考（埋入问题清单） | **只给讲师** |
| `test_commands.md` | 讲师验收测试命令 | **只给讲师** |

---

## 发布方式

W8 周一发布大作业时，把以下内容发给学员：

1. `测试标书.txt`
2. `法规库/` 整个目录
3. 学生讲义中的 `final-project.md`

**不要发** `expected_findings.md` 和 `test_commands.md`。

---

## 验收流程

1. 学员提交代码 + 自己跑出来的 `report.json`
2. 讲师在学员代码目录下运行 `cargo run -- review 测试标书.txt`
3. 对照 `expected_findings.md` 检查：
   - 是否检出至少 3 个埋入问题
   - JSON 格式是否正确
   - 高风险问题是否有法规引用
4. 讲师也可以用自己的测试标书（不同的埋入问题）做附加验收

---

## 自定义测试标书

如果需要调整难度或考察不同的风险类型，可以修改 `测试标书.txt`。
保持格式：`==========` 分隔条款，每条条款包含编号和标题。

埋入问题的设计原则：
- high：明确的法规红线（保证金超标、品牌限定、资质排他）
- medium：不合理但无明确违规（付款周期过长、验收标准模糊）
- low：形式问题（格式不规范、缺必要条件）
- none：正常条款
