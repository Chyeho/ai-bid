# 验收参考：期望检出的问题清单

> ⚠️ 只给讲师看。不要发给学员。

---

## 埋入的 5 个问题

| # | 条款 | 埋入的问题 | 期望风险等级 | 对应法规 | 法规依据 |
|---|---|---|---|---|---|
| 1 | 投标保证金 | 保证金 5%，超过法定上限 | 🔴 **high** | 政府采购法实施条例第43条 | "投标保证金不得超过采购项目预算金额的百分之二" |
| 2 | 计算机设备 | 指定联想品牌，不接受替代 | 🔴 **high** | 政府采购法第22条 / 实施条例第20条 | "不得以任何方式指定品牌" / "限定或者指定特定的专利、商标、品牌或者供应商" |
| 3 | 付款方式 | 验收后 180 天付款 | 🟡 **medium** | 政府采购法第33条 | "自收到发票之日起三十日内支付采购资金" |
| 4 | 投标文件格式 | 缺关键内容（无密封要求） | 🟢 **low** | 政府采购法第42条 | 文件完整性要求 |
| 5 | 供应商资格 | 标准条款，无实质问题 | ⚪ **none** | — | 合法（引用的是政府采购法第22条标准资格条件） |

### 条款 6 的特殊说明

条款 6（售后服务）要求"本地设有常驻服务机构"，这是一个**灰色地带**：
- 加分项：如果学员识别出这可能造成地域限制（违反政府采购法第5条），说明 Agent 敏感度高
- 不减分：如果学员判为 none，也是合理判断——售后服务要求本地化在行业内普遍存在
- **评分策略**：判 high/medium 且理由充分 = 加分；判 none = 不扣分

---

## 验收标准

| 学员检出数 | 得分 | 评级 |
|---|---|---|
| 4+ 问题（含灰色地带） | 25/25 | 优秀 |
| 3 个问题 | 20/25 | 良好 |
| 2 个问题 | 15/25 | 及格 |
| 1 个问题 | 10/25 | 需改进 |
| 0 个问题 | 5/25 | 至少程序能跑 |

> 注意：学员可能检出我们没埋入但说得通的问题。如果理由充分、有法规引用，也算正确检出。

---

## 验收时要看的关键点

1. **高风险必须有法规引用**：条款1和条款2的 reason 字段不应为空
2. **不是乱判**：不能所有条款都判 high（说明 Agent 没有真正分析）
3. **不是全部 none**：不能所有条款都判无风险（说明 Agent 不敢判断）
4. **report.json 格式正确**：JSON 能解析，字段齐全
