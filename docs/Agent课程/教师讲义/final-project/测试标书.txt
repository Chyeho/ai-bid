==========
条款1：投标保证金

投标人须在投标截止时间前缴纳投标保证金。保证金金额为投标总价的百分之五（5%）。
保证金应以银行转账方式缴纳至采购人指定账户。未按时缴纳保证金的投标人将被
视为无效投标。中标人的投标保证金将在合同签订后转为履约保证金。
==========

==========
条款2：计算机设备技术规格

本项目采购的计算机设备（台式电脑200台、笔记本电脑50台）须满足以下技术规格：
- 处理器：英特尔酷睿i7及以上
- 内存：不低于16GB
- 硬盘：不低于512GB固态硬盘
- 品牌要求：须为联想（Lenovo）品牌产品，不接受替代品牌
投标人须提供原厂商针对本项目的授权函及三年质保承诺书。
==========

==========
条款3：项目付款方式

项目验收合格后，采购人在180个自然日内向中标人支付全部合同款项。
付款前中标人须开具等额增值税专用发票。本项目不设预付款和进度款。
==========

==========
条款4：投标文件格式要求

投标文件须装订成册，一式五份（正本一份、副本四份）。投标文件须包含以下内容：
- 投标函
- 法定代表人授权委托书
- 报价一览表
- 技术方案
- 售后服务方案
所有文件须加盖投标人公章。
==========

==========
条款5：供应商资格要求

投标人须满足以下资格条件：
1. 具有独立承担民事责任的能力
2. 具有良好的商业信誉和健全的财务会计制度
3. 具有履行合同所必需的设备和专业技术能力
4. 有依法缴纳税收和社会保障资金的良好记录
5. 参加本次采购活动前三年内，在经营活动中没有重大违法记录
==========

==========
条款6：售后服务要求

中标人须提供不少于12个月的免费质保期。质保期内，中标人应在接到采购人故障
通知后4小时内响应，48小时内到达现场处理。质保期外，中标人应以不高于市场
平均价格提供维修服务。中标人须在本地设有常驻服务机构或承诺中标后30日内设立。
==========
