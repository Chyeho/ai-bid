## 与 G4 的反馈闭环

```
G5 产出工具+Prompt -> G4 注入 Agent 运行 -> G4 跑评测 ->
  -> 反馈报告（Precision/Recall/F1/幻觉率）-> G5 据此优化 ->
    -> G4 再跑评测验证 -> 循环
```

两组不需要知道对方的实现细节。G5 不碰 Agent 调度，G4 不碰 Prompt 怎么写。
