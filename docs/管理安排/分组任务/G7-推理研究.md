# G7 推理研究 — Phase 1-4 完整推进

> 1-2 人 | Python + PyTorch
> 非阻塞研究线，不进主链路，允许失败

---

## Phase 1：方向确认 + 环境搭建（W1-W2）

1. 从以下方向中选 1-2 个：
   - 模型量化（GPTQ/AWQ 4bit -> 降低显存 70%）
   - KV Cache 复用（同文档多条款共享 KV，减少重复计算）
   - 批量推理（Continuous Batching 动态批处理）
   - 模型蒸馏（Qwen-7B -> 3B 标书专用 + LoRA 微调）
   - Layout Embedding（文本+位置+标题+表格关系联合嵌入）
   - 推测解码（小模型草稿 -> 大模型验证，token 生成 2-3x）
2. 申请 GPU 资源（学校审批或云租用，建议 RTX 4090 或 A100）
3. 搭建 PyTorch + transformers + vLLM 实验环境

**Phase 1 交付物**：
- 研究方向确认（选哪 1-2 个方向 + 理由）
- GPU 资源状态（已获批 / 申请中 / 使用云 GPU）
- 实验环境就绪

## 研究方向选择建议

| 方向 | 难度 | 对产品的价值 | 建议 |
|---|---|---|---|
| 模型量化 | 中 | 高（降低部署成本） | 优先选，最容易出成果 |
| KV Cache 复用 | 中 | 高（降低延迟和成本） | 与量化并行选 |
| 批量推理 | 中 | 中（提升吞吐） | 有 GPU 余力时做 |
| 模型蒸馏 | 高 | 很高（标书专用模型） | 有经验的队员选 |
| Layout Embedding | 高 | 中（提升检索精度） | 研究兴趣驱动 |
| 推测解码 | 高 | 中（加速 token 生成） | 有推理优化经验选 |
