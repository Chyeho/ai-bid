# G9 前端 — Phase 1-4 完整推进

> 3-4 人 | React 18 + TypeScript + Vite + Ant Design 5
> 依赖 G8 API | 通过 OpenAPI 契约并行开发

---

## Phase 1：原型+路由（W1-W2）

1. `pnpm install && pnpm dev` 跑通现有前端
2. 搭建路由结构：
   - `/login` `/register` — 登录注册
   - `/dashboard` — 工作台首页
   - `/projects` `/projects/:id` — 项目列表/详情
   - `/projects/:id/audit/:tid` — 审核工作台（核心页面）
   - `/projects/:id/report/:rid` — 审核报告
3. 画审核工作台原型（最核心的页面）：
   - 左栏：PDF 文档预览区（先用 react-pdf 渲染示例 PDF）
   - 右栏：问题列表（Ant Design Table + 展开/折叠 + 按严重度筛选）
   - 左右联动：点击问题 -> 左栏高亮对应位置
4. 跟 G8 对齐 API 格式 -> 用 Mock 数据渲染页面（先不连真实后端）
5. 封装 SSE 客户端 Hook（`useAuditStream`），为 Phase 2 实时进度推送做准备

**Phase 1 交付物**：
- 页面原型可访问（`localhost:5173`）
- 路由结构就绪，核心页面骨架搭建完成
- SSE Hook 封装

## 技术要点

- SSE 流：Vite proxy 对 `/api/chat/stream` 单独配置了 `selfHandleResponse: true`，禁用缓冲确保事件实时推送。其他流式端点同理
- PDF 高亮：后端返回 `block_id` + `bbox` 坐标，前端用 `VITE_HIGHLIGHT_MODE` 控制渲染模式（auto/bbox/text）
- Zustand 状态管理：审核任务状态、SSE 事件流、用户信息
- Ant Design 5 主题：基于 Ant Design 5 Design Token 定制品牌色
