# G3 知识检索 — Phase 1-4 完整推进

> 2 人 | Rust + Qdrant/Milvus + BGE-M3
> 依赖 G1 Schema | 被 G5 search_knowledge 工具调用 | 被 G6 写双库

---

## Phase 1：向量库冷启动（W1-W2）

1. 启动向量库：docker-compose 中的 Milvus 已就绪（端口 19530），或另搭 Qdrant
2. 下载政府采购法 + 实施条例全文 -> 按条款切片（200-800 字/片，保留条款编号 + 所属法规名）
3. 跑通 BGE-M3 向量化：先用 `EMBED_ENGINE=remote`（DashScope API）快速跑通，后续切换 `local`（ONNX 本地推理）
4. 200 条切片向量化入库，每条带元数据：来源、版本、生效日期
5. 定义 `docs/schemas/evidence-set.schema.json`
6. 用 G1 Mock 数据的某条条款手动构造查询 -> 验证检索能命中相关法条
7. 产出 1 份 Mock -> `docs/mocks/sample-evidence-set.json`

**Phase 1 交付物**：
- 向量库搭建完成 + 200 条初始切片入库
- `docs/schemas/evidence-set.schema.json` 初稿
- 1 份 Mock EvidenceSet JSON

## Phase 2：知识库扩充（W3-W5）

1. 知识库扩充到 >= 1500 条，按优先级获取：

   | 优先级 | 来源 | 预估数量 | 获取方式 |
   |---|---|---|---|
   | P0 | 政府采购法及实施条例 | ~200 条 | 官网下载 -> 按条款切片 |
   | P0 | 招标投标法及实施条例 | ~150 条 | 官网下载 -> 按条款切片 |
   | P0 | 财政部规章（74/87/94号令等）| ~300 条 | 财政部官网下载 |
   | P1 | 各省政府采购负面清单 | ~500 条 | 省级政府采购网下载 |
   | P1 | 学校采购相关地方规章 | ~200 条 | 教育厅/财政厅网站下载 |
   | P2 | 财政部投诉处理决定 | ~200 条 | 中国政府采购网公告 |

2. 检索性能达标：检索耗时 < 500ms
3. 实现三路召回：Qdrant 向量匹配 + BM25 关键词 + Neo4j 图遍历（Phase 3 上线）
4. 搭建 HTTP API 供 G5 调用：`GET /knowledge/search?q=&category=&top_k=10`
5. W4 中 HTTP API 就绪，与 G5 联调
6. MVP 阶段不做联网搜索兜底（Phase 3 再加）

**Phase 2 交付物**：
- 知识库 >= 1500 条
- HTTP API 就绪，检索 < 500ms

---

## Phase 3：图库上线+规模扩展（W6-W8）

1. 知识库 >= 3000 条
2. Neo4j 图库上线：>= 1000 节点，法规->条款->案例关系网
3. 图遍历查询 API：`POST /knowledge/graph/query`（2-hop 内返回，< 200ms）
4. 联网搜索兜底：本地未命中时触发 DashScope 联网搜索，结果标记 `_curation_mark` -> G6 后续入库
5. 重排序接入：BGE-Reranker-v2-m3 对召回结果精排

**Phase 3 交付物**：
- 知识库 >= 3000 条
- Neo4j 图库上线（>= 1000 节点）
- 联网搜索兜底就绪
