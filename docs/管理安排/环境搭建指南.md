# 开发环境搭建指南

> 新人入职第一件事：把三个子项目全部跑通。预计耗时 2-4 小时（取决于网络和 Docker 拉镜像速度）。
>
> 最后更新：2026-07-11

---

## 一、你需要安装的工具

| 工具 | 最低版本 | 验证命令 | 说明 |
|---|---|---|---|
| **Rust** | 1.96+ | `rustc --version` | 项目使用 edition 2024 |
| **Java JDK** | 17 | `java --version` | Spring Boot 3.2 要求 |
| **Maven** | 3.8+ | `mvn --version` | Java 后端构建 |
| **Node.js** | 20+ | `node --version` | 前端构建 |
| **pnpm** | 9+ | `pnpm --version` | 前端包管理（`npm i -g pnpm`） |
| **Docker** | 24+ | `docker --version` | 运行 MySQL/Redis/Milvus |
| **Docker Compose** | v2 | `docker compose version` | 一键启动基础设施 |

### Windows 特别说明

- Rust 安装：下载 [rustup-init.exe](https://rustup.rs/)，默认安装 MSVC 工具链即可
- 如遇 `link.exe` 找不到，安装 [Visual Studio Build Tools](https://visualstudio.microsoft.com/zh-hans/downloads/) 并勾选 "C++ 桌面开发" 工作负载
- Git Bash 已自带，所有命令行操作在 Git Bash 或 PowerShell 中执行均可

## 二、项目总览

```
ai-bid/
├── backend-rust/     # Rust 后端 — CLI 工具 + Multi-Agent 审核引擎
├── backend-java/     # Java 后端 — Spring Boot 业务平台
├── frontend/         # React 前端 — Vite + TypeScript
├── docs/             # 项目文档
├── models/           # ONNX 模型文件（~568MB，可选）
└── .env              # 环境变量（API 密钥等，项目根目录）
```

三个子项目的关系：

```
浏览器 (:5173) → 前端 Vite Dev Server
                    ↓ proxy /api
                 Java 后端 (:8086)
                    ↓ 透明代理
                 Rust 引擎 (:3001)
```

## 三、第一步：启动 Docker 基础设施

Java 后端依赖 **MySQL** + **Redis**，Rust 引擎可选依赖 **Milvus**（向量检索）。

所有服务已配置在 `backend-java/src/main/resources/docker-compose.yml`。

```bash
# 进入 docker-compose 所在目录
cd backend-java/src/main/resources

# 启动所有服务（首次会拉取镜像，耗时较长）
docker compose up -d

# 检查服务状态（5 个容器都应显示 healthy 或 running）
docker compose ps
```

启动后的端口映射：

| 服务 | 端口 | 用途 |
|---|---|---|
| MySQL 8.0 | 3306 | Java 后端数据库 |
| Redis 7.2 | 6379 | 缓存 + 消息队列 |
| Milvus 2.6 | 19530 | 向量数据库（Rust 引擎可选） |
| Milvus Attu | 3000 | Milvus Web 管理界面 |
| MinIO | 9000/9001 | Milvus 依赖的对象存储 |
| JODConverter | 8088 | DOCX→PDF 转换服务 |

> **MySQL 自动建库**：docker compose 启动时已创建 `smart_tender_system` 数据库，无需手动建库。root 密码：`1234`。

## 四、第二步：Rust 后端

### 4.1 环境变量

项目根目录 `.env` 已包含必要的 API 密钥和配置。**从 `backend-rust/` 目录运行时**，子目录的 `.env` 会设置 `AIBID_DATA_DIR=..` 将路径解析到项目根。

```powershell
# 确保你在项目根目录 ai-bid/ 下
cd backend-rust

# 验证环境变量能正确加载
cargo run -- --help
```

### 4.2 构建

```powershell
# 快速检查（只编译，不生成二进制）
cargo check

# 完整构建
cargo build

# Release 构建（生产用，首次约 5-10 分钟）
cargo build --release
```

### 4.3 运行测试

```powershell
# 单元测试
cargo test

# Agent 集成测试（需要 API 密钥）
cargo test --bin test_agents -- --test all
```

### 4.4 试用 CLI 审核

```powershell
# 用示例 PDF 跑一遍完整管线（6 阶段：解析→切片→嵌入→Agent审核）
cargo run -- tests/file/研究生院智慧校园项目招标文件.pdf

# 交互式 Chat 模式
cargo run -- --chat tests/file/研究生院智慧校园项目招标文件.pdf
```

### 4.5 常见问题

| 问题 | 解决 |
|---|---|
| `error: linking with link.exe failed` | 安装 VS Build Tools（见第一节 Windows 说明） |
| `models/` 下缺少 ONNX 文件 | 首次运行 `EMBED_ENGINE=local` 时自动下载（~568MB），或用 `EMBED_ENGINE=remote` 跳过 |
| API 调用超时/401 | 检查 `.env` 中 `DASHSCOPE_API_KEY` 或 `OPENAI_API_KEY` 是否正确 |
| `AIBID_DATA_DIR` 路径错误 | 从 `backend-rust/` 运行时确保子目录 `.env` 第一行是 `AIBID_DATA_DIR=..` |

## 五、第三步：Java 后端

### 5.1 确认 Docker 服务就绪

```bash
# MySQL 必须已启动且可连接
docker exec smart-mysql mysql -uroot -p1234 -e "SHOW DATABASES;"
# 输出应包含 smart_tender_system
```

### 5.2 编译

```bash
cd backend-java

# 首次构建会下载大量 Maven 依赖（国内用户已配置阿里云镜像加速）
mvn clean package -DskipTests
```

### 5.3 启动

```bash
# 方式一：Maven 插件
mvn spring-boot:run

# 方式二：直接运行 jar
java -jar target/smart_tender-0.0.1-SNAPSHOT.jar
```

### 5.4 验证

```bash
# 健康检查
curl http://localhost:8086/actuator/health

# 预期返回: {"status":"UP",...}
```

> **关于端口**：`application.yml` 激活了 `prod` profile（`spring.profiles.active: prod`），因此 `application-prod.yml` 覆盖端口为 **8086**。前端 Vite proxy 也配置为 `http://127.0.0.1:8086`，两者一致。

### 5.5 关键配置说明

| 配置项 | 值 | 位置 |
|---|---|---|
| 数据库 | `localhost:3306/smart_tender_system` | `application.yml` |
| Redis | `localhost:6379` (db 10) | `application.yml` |
| Rust 引擎 | `http://127.0.0.1:3001` | `application.yml` rust.api.base-url |
| 文件存储 | `D:/smart-tender/data` | `application.yml` file.storage.path |

### 5.6 常见问题

| 问题 | 解决 |
|---|---|
| 数据库连不上 `CommunicationsException` | `docker compose ps` 确认 MySQL 在运行 |
| 表不存在 | Flyway 默认禁用，表由 MyBatis-Plus 自动建或手动执行 SQL |
| 端口被占用 | 修改 `application.yml` 中 `server.port` |
| Maven 下载慢 | 已配置阿里云镜像，如仍慢检查 `~/.m2/settings.xml` |

## 六、第四步：前端

### 6.1 安装依赖

```bash
cd frontend

# 安装依赖（首次约 1-2 分钟）
pnpm install
```

### 6.2 启动开发服务器

```bash
pnpm dev
# 默认在 http://127.0.0.1:5173 启动
```

### 6.3 验证

浏览器打开 `http://127.0.0.1:5173`，应该看到审核工作台页面（即使没有数据，UI 框架应正常渲染）。

### 6.4 前端代理说明

Vite 开发服务器将 `/api` 请求代理到 Java 后端：

```
前端请求 /api/xxx  →  Vite proxy  →  http://127.0.0.1:8086/api/xxx
```

所以前端开发时不需要单独配置后端地址，前提是 **Java 后端已在 8086 端口启动**。

### 6.5 常见问题

| 问题 | 解决 |
|---|---|
| `pnpm: command not found` | `npm install -g pnpm` |
| API 请求 502 | Java 后端未启动或端口不对 |
| 页面空白 | 检查浏览器控制台报错；确认 Node.js ≥ 20 |
| `react-pdf` 相关报错 | `pnpm install` 重新安装 |

## 八、快速诊断脚本

在项目根目录下运行，一键检查所有依赖：

```powershell
# PowerShell 诊断脚本
Write-Host "=== 环境诊断 ===" -ForegroundColor Cyan

Write-Host "`n[工具链]" -ForegroundColor Yellow
rustc --version 2>&1 | Write-Host -ForegroundColor $(if ($?) { 'Green' } else { 'Red' })
cargo --version 2>&1 | Write-Host
java --version 2>&1 | Select-Object -First 1 | Write-Host
mvn --version 2>&1 | Select-Object -First 1 | Write-Host
node --version 2>&1 | Write-Host
pnpm --version 2>&1 | Write-Host
docker --version 2>&1 | Write-Host

Write-Host "`n[Docker 服务]" -ForegroundColor Yellow
docker compose -f backend-java/src/main/resources/docker-compose.yml ps 2>&1 | Write-Host

Write-Host "`n[端口监听]" -ForegroundColor Yellow
@(3306, 6379, 19530, 8086, 3001, 5173) | ForEach-Object {
    $port = $_
    $listening = (Get-NetTCPConnection -LocalPort $port -ErrorAction SilentlyContinue).Count
    $status = if ($listening -gt 0) { "Green" } else { "DarkGray" }
    Write-Host "  Port $port : $($listening) connections" -ForegroundColor $status
}

Write-Host "`n[文件检查]" -ForegroundColor Yellow
@(".env", "backend-rust/Cargo.toml", "backend-java/pom.xml", "frontend/package.json") | ForEach-Object {
    $exists = Test-Path $_
    $status = if ($exists) { "Green" } else { "Red" }
    Write-Host "  $_ : $(if ($exists) { 'OK' } else { 'MISSING' })" -ForegroundColor $status
}

Write-Host "`n=== 诊断完成 ===" -ForegroundColor Cyan
```
