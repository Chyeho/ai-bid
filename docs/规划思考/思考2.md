## 四、研究突破
学习该方向上。当前领域最优、业界顶尖效果。
文档解析与理解
• Docling (IBM)：2024年开源，将PDF转为统一的DoclingDocument格式（含布局、表格、层级），支持导出Markdown/JSON，是当前工程化最好的工具。
• MinerU：可提取高质量PDF内容，在复杂中文表格上表现优异，可配合pdf2image做视觉端提取。
• Florence-2 (Microsoft)：轻量级多模态基础模型，微调后可同时做版面分析、OCR、表格结构识别，单图推理速度极快，适合做解析层引擎。
• Qwen2.5-VL / InternVL2：可作为“整页理解”后端，直接让模型输出页面全部字段的结构化JSON，适合极致简化流水线（但成本较高，建议用量化版做批量提取）。
文档审核与检查专用方法
• LayoutLMv3 / LiLT：将文本、布局、图像对齐在一个框架中，微调后可做段落分类、标志性内容检测（如“此处应盖章”判断）。
• UDOP (2023) 与 DocFormerv2：统一视觉、文本和布局的预训练，在表单理解、缺失内容检测上SOTA，可用来判断表格是否有未填写的必填项。
• Pix2Struct：擅长将截图结构化为HTML/JSON，适合处理复杂的嵌套表格和价格清单。
• DocVQA / DUDE / OmniDocBench：可从中构造审核测试集。特别推荐OmniDocBench (2024)，覆盖多种文档理解任务，可评估提取后结构化质量。
法律/合同专项
• LegalLens (2024)：针对法律合同的不公平条款检测、缺失项检测数据集和方法，可直接复用到投标“条款异常”判断。
• LexGLUE / CUAD：合同理解基准，上有很多微调Transformers的思路可迁移。
